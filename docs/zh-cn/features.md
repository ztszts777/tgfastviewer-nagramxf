# 功能

在插件列表打开「NagramXF Enhancements」的设置，可按需开关各项功能。

## 媒体浏览 {#media-browsing}

- **快速浏览**在打开照片或视频时优先加载附近媒体，左右滑动到边缘时继续补载，并且保留完整相册。
- **缩略图栏**支持跨消息浏览。点小箭头展开或收起，拖动可以调整大小。竖屏默认放在底部、初始收起，并按聊天记忆开合状态。
- **在媒体库中查看**会打开共享媒体网格，并标出当前媒体。返回时先回到查看器，再回到聊天。

## AyuGram 过滤 {#ayugram-filters}

开启「同步 AyuGram 过滤」后，聊天预览、置顶栏、共享媒体、文件和全屏浏览会沿用各聊天当前的过滤及排除设置。过滤后没有可见消息的日期栏会隐藏，聊天预览可显示最近一条未过滤消息。

如果最新加载的消息被过滤，在聊天中跳到最新位置时，插件会使用 NagramXF 的原生已读流程更新未读数。

## 视频与音乐 {#video-and-music}

| 功能 | 使用方法 |
| --- | --- |
| **视频设置** | 点齿轮调整倍速、可选画质和播放模式，也可开启后台听视频。 |
| **播放模式** | 「播完停止」「连续播放」「循环播放」三选一。 |
| **后台听视频** | 在视频设置中开启。离开查看器后可用顶部播放栏控制。设置按聊天保存。 |
| **系统画中画与播控** | 在视频菜单进入系统小窗。系统播控支持播放、暂停和前后跳转 15 秒，能取得标题或封面时也会显示。 |
| **音乐工具栏** | 两行按钮提供播放、倍速、定时及「在聊天中查看」等操作。可在设置中隐藏「添加到个人资料」。 |
| **睡眠定时** | 点视频或音乐播放器的时钟。预设为 **15 到 120 分钟**，自定义支持 **1 到 1440 分钟**。可选「播完当前媒体再停止」。 |

## 手势与旋转 {#gestures}

| 手势 | 效果 |
| --- | --- |
| 双击画面中央 | 播放或暂停。 |
| 双击左右两边 | 后退或前进，秒数跟随 NagramXF 原生设置。 |
| 长按画面或播放器空白处 | 临时加速，默认 **2.5×**，松手恢复。 |
| 双指缩放与拖动 | 缩放和平移画面，点还原按钮恢复。 |
| 在宽视频画面中央下滑或上滑 | 分别进入或退出全屏。 |
| 在左侧或右侧上下滑 | 分别调节亮度、媒体音量。退出查看器时恢复原值。 |

亮度和音量手势默认每 1% 轻振一次，强度为 60%，频率上限为每秒 30 次。宽度大于高度的视频可以在打开时自动横屏，左右切换媒体时默认关闭自动旋转。
