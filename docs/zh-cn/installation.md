# 安装

## 版本要求 {#requirements}

- 需要带插件引擎的 **NagramXF 12.10.1 或更新版本**。插件入口在「N-设置 → 插件」。
- 已通过 Python 回归测试，并核对了 NagramXF **12.10.1.1251**（构建 `30dcd6c`，`arm64-v8a`）的客户端接口。v1.7.0 设置页滚动修复已通过真机验证。[已核验的客户端版本](https://github.com/Keeperorowner/NagramXF/releases/tag/1251)

## 安装插件 {#install}

1. 从 GitHub Releases [下载 `nagramxf_media_suite.plugin`](https://github.com/ztszts777/tgfastviewer-nagramxf/releases/latest/download/nagramxf_media_suite.plugin)。
2. 在 NagramXF 打开「N-设置 → 插件」，确认插件引擎已启用。
3. 点击「＋」导入文件，启用「NagramXF 媒体增强」。
4. 打开插件设置，按需调整[功能](/zh-cn/features)。

插件默认跟随 Android 系统语言。可在「插件语言」手动选择「简体中文」或「English」。两种语言包含在同一个插件文件中。

## 更新已有插件 {#update}

导入新版文件并选择「更新」，即可沿用已有设置。如装有功能重叠的旧版独立插件，可以停用对应插件，避免控件重复。

了解本次改动可查看[更新记录](/zh-cn/changelog)，安装遇到问题可查看[常见问题](/zh-cn/faq)。
