# Installation

## Requirements {#requirements}

- NagramXF **12.10.1 or newer** with the plugin engine. Open **N Settings → Plugins** to find it.
- The suite’s Python regressions and client interface checks passed against NagramXF **12.10.1.1251** (build `30dcd6c`, `arm64-v8a`). The v1.7.0 settings scroll fix was also tested on a phone. [Tested client build](https://github.com/Keeperorowner/NagramXF/releases/tag/1251)

## Install the plugin {#install}

1. [Download `nagramxf_media_suite.plugin`](https://github.com/ztszts777/tgfastviewer-nagramxf/releases/latest/download/nagramxf_media_suite.plugin) from GitHub Releases.
2. In NagramXF, open **N Settings → Plugins** and enable the plugin engine.
3. Tap **+**, select the downloaded file, and enable **NagramXF Media Enhancements**.
4. Open the plugin’s settings to select the [features](/features) you want.

The plugin follows the Android system language by default. In **Plugin language**, choose **English** or **简体中文** to override it. Both languages are included in the same file.

## Update an existing installation {#update}

Import the latest file and choose **Update**. The suite reuses your existing settings. If you have older standalone plugins that cover the same features, disable them when using the suite to avoid duplicate controls.

See the [changelog](/changelog) for changes or the [FAQ](/faq) for help with setup.
