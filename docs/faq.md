# FAQ

## Why is the Plugins menu missing? {#plugins-menu}

Make sure you are using a NagramXF build with the plugin engine. The suite requires NagramXF 12.10.1 or newer. Follow the [installation guide](/installation) for the tested build and setup steps.

## Why do I see duplicate controls? {#duplicate-controls}

Check the list of enabled plugins for older standalone versions with the same feature. Disable the overlapping plugin and reopen the player.

## Why is a message missing in the media viewer? {#filters}

Open the chat’s AyuGram settings and check which filter rules are active for that chat. When **Apply AyuGram filters** is enabled, fullscreen browsing and the shared media grid use those rules as well.

## Where is the thumbnail strip? {#thumbnails}

Tap the small handle at the bottom of the portrait viewer or at the edge of the landscape viewer. Drag the handle to resize the strip. In the plugin settings, you can change the portrait position, the default open state, and whether that state is remembered per chat or globally.

## Why can’t I open picture-in-picture? {#picture-in-picture}

Allow picture-in-picture for NagramXF in Android settings, then verify that **System picture-in-picture** is on in the plugin. Start video playback before trying the floating player.

## Can I change the seek gesture and rotation behavior? {#gestures}

Set the double-tap seek interval in NagramXF. Use the plugin’s **Fullscreen and rotation** settings to control whether wide videos rotate on entry and whether switching to another media item can rotate the viewer.

## What should I include in a bug report? {#report}

Include the NagramXF version and build, Android version, plugin version, enabled features, and steps to reproduce. If the issue occurs only with a particular media type or in one orientation, mention that too. [Report an issue](https://github.com/ztszts777/nagramxf-enhancements/issues)
